# ME0212 Study Lab

Interactive study platform for ME0212 Electrical Circuits and Machines, German Jordanian University.
The site is the single file `index.html`. It needs no build step and works offline.

Chapters: 1, 2, 3, 4, 5, 6, 8 and 9 (the numbering of the textbook).
Chapters 7 (transients), 10 (RLC and resonance) and 11 (transformers) are not included yet.
